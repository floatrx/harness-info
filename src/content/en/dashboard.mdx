## Open it

In the harness-demo checkout, run:

```bash
pnpm dashboard
```

Then open `http://127.0.0.1:4777`. The dashboard listens on 127.0.0.1 only. Its buttons write the same files as the
CLI, so you can use both side by side. What Start, Pause, Resume and Stop do is on [Running the loop](/loop).
